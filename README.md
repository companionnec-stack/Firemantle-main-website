# 🔥 Firemantle Gospel Outreach Ministry Website

A modern and responsive website built for **Firemantle Gospel Outreach Ministry**, showcasing the ministry's vision, mission, media arm, gallery, and contact information.

The website is designed to inspire visitors, share the Gospel, and highlight the ministry's impact through media and outreach.

---

## 🌟 Features

- Responsive Navigation Bar
- Hero Section
- About the Ministry
- Vision & Mission
- Ministry Arms
- Firemantle Films Production
- Embedded YouTube Video
- Interactive Image Gallery
- Fullscreen Lightbox Gallery
- Previous & Next Image Navigation
- WhatsApp Integration
- Social Media Links
- Smooth Scrolling
- Responsive Design
- Modern UI with Tailwind CSS
- Animations with Framer Motion

---

## 🛠️ Built With

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- React Icons
- Framer Motion

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/firemantle-website.git
```

Navigate into the project:

```bash
cd firemantle-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📦 Packages Used

```bash
npm install tailwindcss @tailwindcss/vite
npm install react-icons
npm install framer-motion
```
